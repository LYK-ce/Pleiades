# Pleiades 优化编译方案

本文档整理了 Pleiades 项目在不同平台和场景下的优化编译方法，旨在最大化推理性能。

## 编译配置总览

| 场景 | 命令 | 预期加速 |
|------|------|---------|
| 基础 Release | `cargo build --release` | 基准 |
| + Native CPU 指令集 | `RUSTFLAGS="-C target-cpu=native" cargo build --release` | 2-5× |
| + Intel MKL | `features = ["mkl"]` + native | 3-8× |
| + CUDA GPU | `features = ["cuda"]` | 10-50× |
| CPU-only 部署版 | `--no-default-features` + native | 最佳 CPU 性能 |

---

## 1. Release 模式（必须）

Debug 模式与 Release 模式的性能差距在 **10-50 倍**，这是最基本的优化。

```bash
# ❌ 默认 debug 模式（极慢）
cargo build
cargo test --test test

# ✅ Release 模式
cargo build --release
cargo test --test test --no-run --release
```

---

## 2. Native CPU 指令集（强烈推荐）

默认编译目标为 `x86_64-unknown-linux-gnu` 或 `x86_64-pc-windows-msvc`，只使用最基础的 SSE2 指令集。通过 `-C target-cpu=native` 启用当前 CPU 的全部 SIMD 指令（AVX2、AVX-512、NEON 等），对量化矩阵运算有显著提升。

### Windows (cmd)

```cmd
set RUSTFLAGS=-C target-cpu=native
cargo build --release
```

### Windows (PowerShell)

```powershell
$env:RUSTFLAGS="-C target-cpu=native"
cargo build --release
```

### Linux / macOS

```bash
RUSTFLAGS="-C target-cpu=native" cargo build --release
```

### 编译测试二进制文件

```bash
RUSTFLAGS="-C target-cpu=native" cargo test --test test --no-run --release
```

> **注意**：`target-cpu=native` 生成的二进制**只能在同架构 CPU 上运行**。如果目标设备的 CPU 不支持某些指令集（如开发机有 AVX-512 但部署设备没有），程序会崩溃。跨设备部署时应使用 `target-cpu=x86-64-v3`（AVX2 级别，大多数现代 CPU 支持）或不设置此选项。

### 常用 CPU 级别

| 值 | 指令集 | 适用范围 |
|----|--------|---------|
| `native` | 当前 CPU 的全部指令 | 仅本机运行 |
| `x86-64-v3` | AVX2 + FMA | 2013年后的 x86 CPU |
| `x86-64-v4` | AVX-512 | 较新的 Intel/AMD |
| `x86-64` | SSE2（默认） | 所有 x86-64 CPU |

## 3. Intel MKL 加速（Intel CPU 推荐）

Intel Math Kernel Library 对矩阵运算有极致优化，在 Intel CPU 上效果显著。

### 前置条件

安装 Intel oneAPI MKL：
- Windows: 从 [Intel oneAPI](https://www.intel.com/content/www/us/en/developer/tools/oneapi/onemkl-download.html) 下载安装
- Linux: `sudo apt install intel-mkl` 或从 Intel 官网安装

### Cargo.toml 配置

```toml
[features]
default = ["cuda"]
cuda = ["candle-core/cuda", "candle-nn/cuda", "candle-transformers/cuda"]
mkl = ["candle-core/mkl", "candle-nn/mkl", "candle-transformers/mkl"]

[dependencies]
candle-core = { version = "0.9.2" }
candle-nn = { version = "0.9.2" }
candle-transformers = { version = "0.9.2" }
```

### 编译命令

```bash
# MKL + Native（最佳 Intel CPU 性能）
RUSTFLAGS="-C target-cpu=native" cargo build --release --features mkl --no-default-features

# MKL + CUDA
RUSTFLAGS="-C target-cpu=native" cargo build --release --features mkl,cuda
```

> **注意**：MKL 在 AMD CPU 上也能运行，但可能不会启用全部优化。AMD CPU 建议使用 OpenBLAS 替代（candle 暂不直接支持）。

---

## 4. CUDA GPU 加速

CUDA 是最快的推理方式，适合有 NVIDIA GPU 的设备。

### 前置条件

- NVIDIA GPU
- CUDA Toolkit 安装（提供 `curand64_10.dll`、`cublas64_12.dll` 等运行时库）

### Cargo.toml 配置

```toml
[features]
default = ["cuda"]
cuda = ["candle-core/cuda", "candle-nn/cuda", "candle-transformers/cuda"]

[dependencies]
candle-core = { version = "0.9.2" }
candle-nn = { version = "0.9.2" }
candle-transformers = { version = "0.9.2" }
```

### 编译命令

```bash
# CUDA 版（默认）
cargo build --release

# CUDA + Native CPU（CPU fallback 时也有优化）
RUSTFLAGS="-C target-cpu=native" cargo build --release
```

### 部署 CUDA 版到其他设备

如果目标设备有 GPU 但没有安装 CUDA Toolkit，需要拷贝以下 DLL 到 exe 同目录：

```
cublas64_12.dll
cublasLt64_12.dll
curand64_10.dll
cudart64_12.dll
```

这些文件位于开发机的 `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\vXX.X\bin\` 目录下。

---

## 5. CPU-only 部署版

适用于无 GPU 或无 CUDA Toolkit 的目标设备。

```bash
# CPU-only + Native 指令集（最佳 CPU 纯版性能）
RUSTFLAGS="-C target-cpu=native" cargo test --test test --no-run --release --no-default-features

# CPU-only + 兼容模式（可在任意 x86-64 设备上运行）
cargo test --test test --no-run --release --no-default-features
```

---

## 6. 跨平台编译

### Linux 目标（从 Windows）

推荐使用 WSL：

```bash
# 在 WSL 中
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
cd /mnt/c/workspace/Workspace/Workspace/Pleiades
RUSTFLAGS="-C target-cpu=native" cargo test --test test --no-run --release --no-default-features
```

### ARM 目标（如树莓派）

```bash
# 在树莓派上直接编译
RUSTFLAGS="-C target-cpu=native" cargo build --release --no-default-features
```

ARM NEON 指令集会通过 `target-cpu=native` 自动启用。

## 7. 推荐编译方案总结

### 开发机（有 CUDA）

```cmd
set RUSTFLAGS=-C target-cpu=native
cargo build --release
```

### 部署到有 GPU 的设备

```cmd
set RUSTFLAGS=-C target-cpu=x86-64-v3
cargo test --test test --no-run --release
:: 拷贝 exe + CUDA DLLs + 模型文件到目标设备
```

### 部署到无 GPU 的设备

```cmd
set RUSTFLAGS=-C target-cpu=x86-64-v3
cargo test --test test --no-run --release --no-default-features
:: 拷贝 exe + 模型文件到目标设备（无需 CUDA DLL）
```

### 部署到 Intel CPU 设备（最大 CPU 性能）

```cmd
set RUSTFLAGS=-C target-cpu=native
cargo test --test test --no-run --release --features mkl --no-default-features
:: 需要目标设备也有 MKL 运行时
```

## 8. 性能对比参考

以 Qwen3-0.6B Q8_0 模型为基准：

| 编译方案 | 设备 | 预期速度 |
|---------|------|---------|
| Release + CUDA | RTX 3060 | ~30-50 token/s |
| Release + CUDA | RTX 4090 | ~80-120 token/s |
| Release + native + MKL | Intel i7-12700 | ~5-15 token/s |
| Release + native | Intel i7-12700 | ~3-8 token/s |
| Release（默认） | Intel i7-12700 | ~1-3 token/s |
| Debug（默认） | 任意 CPU | ~0.1-0.3 token/s |

> 数据仅供参考，实际性能因硬件、模型大小、量化级别等因素而异。

## 9. 未来优化方向

| 方向 | 说明 |
|------|------|
| **llama.cpp 后端** | 替换 candle 推理层，使用 llama.cpp 的极致优化 SIMD 内核，可获得接近原生 llama.cpp 的速度 |
| **OpenBLAS** | AMD CPU 上替代 MKL 的选择 |
| **Metal** | macOS 上的 GPU 加速（candle 已支持 `metal` feature） |
| **量化级别选择** | Q4_0/Q4_K 模型比 Q8_0 快约 2 倍，精度略有下降 |
