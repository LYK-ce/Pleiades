# 小车问题：Binah 四轮停转不同步

> 创建日期：2026-08-04
> 状态：已确认（小车固有特性）

## 问题描述

**Binah** 小车在**停车时四个轮子不会同时停转**，每次停车车体会往左偏一下。

## 实验确认（2026-08-04）

**实验方法**：车轮悬空（架空），前进后停下，观察四个轮子的停止顺序。

**结果**（每次复现，稳定一致）：

```
停止顺序：左后轮 最先停 → … → 右前轮 最后停
```

- 左后轮最先停止（内部摩擦/传动阻力最大）
- 右前轮最后停止（惯性滑行最久）
- 每次都是同一顺序，无随机性

## 原因分析

- 四轮独立电机 + 减速箱存在**机械个体差异**（电机内部摩擦、传动阻力不同）
- Stop 命令后为自然滑行停止（PWM=0），停转时间由各轮自身摩擦决定
- 物理上不可能四个轮摩擦完全一致 → 停转不同步是必然

## 结论

- **小车固有特性，非代码问题**（已排查确认：驱动协议、停车逻辑正常）
- 地面行驶时表现为：停车瞬间车体发生确定性小旋转 + 位移（偏左）
- 该运动**编码器无法感知**（轮子滑行 ≠ 车体运动），odom 位置会丢失这段位移；yaw 变化可被 IMU 捕捉

## 影响与应对

| 层面 | 应对 |
|------|------|
| 建图/定位 | 每次停车引入确定性位姿误差 → 地图涂抹、odom 漂移（主要累积在横向） |
| 代码缓解（治标） | 停车后用 IMU 陀螺积分补偿残余旋转 + 运动学模型补算位移；或打滑检测 |
| 根治（长期） | **激光雷达 scan-to-map 匹配校准**（ICP/直线拟合校正 odom），吸收所有 odom 不可感知的运动误差 |
