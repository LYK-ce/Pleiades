## 6. 系统架构

本平台采用 **飞控与机载计算分离（Decoupled Architecture）** 的系统设计：

| 组成 | 规格 |
|---|---|
| 飞控系统 | Pixhawk 2.4.8 + ArduPilot |
| 机载计算 | Raspberry Pi 4B |
| 操作系统 | Ubuntu 22.04 |
| 内存 | 8 GB |
| 通信方式 | USB / UART 遥测通信 |
| 动力电池 | 5400 mAh Li-ion |

**系统特点**：飞控与机载计算解耦设计，提高系统稳定性与安全性，同时为算法开发与功能扩展提供更高灵活性。

## 7. 快速开始（装机 / 接电 / 首次配置）

### 7.1 桨叶安装与首次飞行

四旋翼电机转向与桨叶安装方向：

| 电机 | 转向 | 桨叶颜色 |
|---|---|---|
| 右前（1 号） | 逆时针 CCW | 红色桨 |
| 左后（3 号） | 逆时针 CCW | 红色桨 |
| 左前（4 号） | 顺时针 CW | 白色桨 |
| 右后（2 号） | 顺时针 CW | 白色桨 |

**安装原则**：逆时针电机配逆时针桨（红色桨），顺时针电机配顺时针桨（白色桨）。安装完成后，对角线方向桨叶颜色一致。

**遥控器开机前摇杆与开关位置**：左侧油门摇杆必须拉到最下方，右侧方向/俯仰摇杆保持居中，左右上方开关拨到上方位置。确认无误后再打开遥控器电源。

### 7.2 电池连接说明

- 电源接口位于机身后部下方，采用 **XT60 电源插头**。
- 注意事项：
  - 连接电池前先关闭遥控器油门，确认桨叶未安装或周围无人。
  - 红线为正极（+），黑线为负极（-），**禁止反接**。
  - 插接应一次性插到底，避免虚接。
  - 飞行结束后及时断开电池。
  - 飞行前确保电池电量充足（4S 电池电压 ≥ 15.2V），建议连接 BB 响报警器监控电量。

### 7.3 Mission Planner 快速入门

Mission Planner 是 ArduPilot 官方推荐的地面站软件，用于飞控参数配置、传感器校准、航线规划、飞行数据分析。

**核心界面**：
- 飞行数据 (Flight Data) — 实时姿态、传感器数据、卫星地图
- 飞行计划 (Flight Plan) — 航线规划、航点设置
- 初始设置 (Initial Setup) — 机架选择、加速度计/罗盘/遥控器校准
- 配置/调试 (Config/Tuning) — 全部参数列表、PID 调参
- 模拟器 (Simulation) — SITL 软件在环仿真

**连接飞控**：USB 连接 → 选择 COM 口 → 波特率 115200 → 点击 Connect。

**固件安装**：初始设置 → 安装固件 → 选飞控型号 → 选固件类型（ArduCopter 多旋翼 / ArduPlane 固定翼 / ArduRover 车船）。烧录中勿断开 USB，否则可能变砖。

**传感器校准**：
1. 加速度计校准 — 6 个方向（水平/左侧/右侧/机头向下/机头向上/背面向下）
2. 罗盘校准 — 各方向缓慢旋转约 30 秒
3. 遥控器校准 — 所有摇杆和开关拨到最大行程，通道值范围 1000–2000
4. 电调校准 — 确保所有电机转速一致

**日志分析**：飞行数据 → 数据闪存日志 → 下载日志 → Log Viewer。常用指标：IMU 加速度计曲线（振动）、RCIN/RCOU 通道值、GPS 数据。

**常用快捷键**：Ctrl+E 连接/断开、Ctrl+F 飞行数据、Ctrl+P 飞行计划、Ctrl+S 保存参数。

## 8. 飞控调试（解锁 / 报警 / 驱动 / 模式）

### 8.1 飞控报警列表（无法解锁黄灯）

| 报警信息 | 原因及解决方法 |
|---|---|
| RC not calibrated | 遥控器未校准，需校准遥控器 |
| Compass not calibrated | 罗盘未校准 |
| Compass not healthy | 罗盘硬件故障（外置未接好/内置或外置损坏） |
| Compasses inconsistent | 内外罗盘方向不一致（>45°），重装 GPS 模块对齐箭头 |
| GPS Glitch | GPS 故障或接线错误 |
| Need 3D Fix | GPS 未定位（Loiter/RTL/AUTO 模式需要），或室内设了电子围栏 |
| High GPS HDOP | HDOP > 2.0 定位精度不够（室外建议 HDOP<1 再解锁） |
| Baro not healthy | 气压计故障 |
| Alt disparity | 气压计读数有差异，自检 30 秒内勿移动 |
| INS not calibrated | 加速度计未校准 |
| Accels not healthy | 加速度计故障 |
| Gyros not healthy | 陀螺仪故障 |
| Check Board Voltage | 飞控供电不在 4.5–5.5V |
| safety switch | 安全开关未关闭，长按至灯长亮 |
| RCx minimum is greater than trim | 遥控器辅助通道开关未校准 |
| Bad AHRS | 姿态解算错误，重校加速度计 |

### 8.2 无法解锁排查

- **A. 初始设置**：机架类型选择、加速度计/指南针/遥控器校准、飞行模式（Loiter 需 GPS 定位）、电调校准。
- **B. 安全开关**：Pixhawk 默认使能安全开关，解锁前先长按；不想用则设 `BRD_SAFETYENABLE=0`。
- **C. 起飞瞬间转头**：检查桨、电机转向（1/2/3/4 非顺时针排布）、姿态方向；部分飞机调参/刚性/动力问题属正常现象。
- **D. 绿灯快闪**：GPS 使用 SBAS（星基增强），定位更佳。
- **E. 推油门起不来**：电池没电、桨转向反、电调未做行程校准（先校遥控器后校电调）。
- **F. 起飞瞬间侧翻**：检查电调线序、绑飞测试、怠速查电机转向、查桨、重校电调行程、查飞控是否装反。
- **G. 遥控器无法校准**：查接收机供电/对频、RC IN 接口、线序、换线、重刷固件。

### 8.3 驱动安装（Mission Planner 无法识别 COM 口）

- 方法一：安装 MSI 版 Mission Planner（自带驱动）。
- 方法二：安装 Arduino IDE（自动装驱动）。
- 方法三：驱动精灵扫描修复。
- 排查：数据线需支持数据传输；COM 口过大（如 COM283）可改为 COM3–COM10。
- 连接成功标志：状态栏绿色"连接"图标，能正常读取飞控数据。

### 8.4 飞行模式详解

| 模式 | 说明 | 适用场景 |
|---|---|---|
| 稳定模式 (Stabilize) | 自动水平，俯仰/横滚控角度，方向控旋转速率，油门控高度 | 室内飞行、无 GPS 环境 |
| 定高模式 (ALT_HOLD) | 自动油门保持高度，油门有死区，超死区才升降 | 室内飞行、无 GPS 环境 |
| 悬停模式 (Loiter) | GPS 定点 + 气压定高 | 室外飞行、新手练习 |
| 返航模式 (RTL) | 需 GPS，升高到 15m 后飞回 Home | 失控/一键返航 |
| 自动任务 (AUTO) | 执行 Mission Planner 预设航线（航点高度/速度/悬停/拍照/返航） | 航线飞行 |
| 降落模式 (Land) | 垂直下降，WPNAV_SPEED_DN 限速 | 降落 |
| 绕圈模式 (Circle) | 以当前位置为圆心绕圈，机头始终指向圆心，可遥控移动圆心 | 环绕观察 |

**解锁/上锁（美国手）**：
- 解锁：油门最低 + 方向最右（左摇杆 ↙ 右下角），保持 2 秒 → 电机怠速。
- 上锁：油门最低 + 方向最左（左摇杆 ↖ 左下角），保持 2 秒；或油门最低 20 秒自动上锁。

### 8.5 飞行注意事项

- 首次飞行在室外空旷处；远离机场/禁飞区/人群/高压线。
- 先试机桨叶试飞，对照机臂标签安装（有字一面朝上）。
- GPS 模块箭头前向必须与机头前向一致，否则无法解锁。
- BB 响务必插在电池平衡口。
- 通电后自检约 1 分钟，勿挪动飞机；室外 3~5 分钟搜星。
- LED 指示灯：蓝色 = 未定位；绿色 = 定位成功可起飞。
- 起飞地效导致侧倾时，右边摇杆辅助修正姿态，勿只推油门。
- 手动降落不可急速拉低油门（会坠机），应匀速降落。

## 9. 供电与遥控（电池 / 安全 / 遥控器）

### 9.1 电池充电 / 放电 / 保存 / 应急

- **充电**：4S 电池充电上限电压 16.8V，勿过充；平衡充模式，充电电流通常 1C–2C；充电时有人值守，远离易燃物。
- **放电**：单片电芯 < 3.3V 即过放（会鼓包）；最大放电电流 `I = 放电倍率 × 容量(Ah)`（例：2200mAh 45C → 99A）。
- **保存**：单片存放电压约 3.85V，超 2 天不用转存储模式；避免极端温度、撞击挤压；建议防爆柜存放。
- **应急**：锂电起火**切勿用水**，用干粉灭火器/沙子/防火毯覆盖；冒烟发热移至室外空旷处。
- **过放解救**：镍氢模式极低电流（0.1–0.5A）充至 3.0V 以上，再转锂电平衡充；全程值守；严重鼓包直接回收。

### 9.2 BB 响使用

- 插入电池平衡接口（白色插头），**最右侧红线为正极，与 BB 响正极对齐，切勿反插**。
- 单节电压 < 3.3V 蜂鸣报警提醒降落。
- 飞行中建议一直插着 BB 响作为实时电压监控。

### 9.3 FlySky FS-i6 遥控器

- 规格：六通道，2.4GHz AFHDS，传输距离约 800–1000m，4 节 AA 电池或 2S 锂电池。
- 通道配置：CH1 横滚 / CH2 俯仰 / CH3 油门 / CH4 偏航 / CH5 飞行模式（SWC 三档）/ CH6 辅助。
- 通电前：油门摇杆最低、其余居中、模式开关在稳定模式。

### 9.4 RadioMaster ATS9 Pro 遥控器（选配）

- 规格：九通道，EdgeTX 开源系统（触摸屏），2.4GHz 多协议高频头（4-in-1 / ELRS），约 1.5–2km，2S 18650 锂电（7.4V），4.3 英寸彩屏。
- 通道：CH1–CH4 同 FS-i6；CH5 飞行模式（SA 三档）/ CH6 避障（SB）/ CH7 相机快门/灯光（SC）/ CH8 紧急降落/返航（SD）/ CH9 云台俯仰（S1 旋钮）。
- 特色：语音播报、遥测回传、USB 模拟器、RSSI 预警、逻辑开关、SD 卡模型存储。

## 10. 定位与光流（GPS / 光流 / EKF 切换）

> 注意：飞控固件需升级到 4.1.0 及以上，操作前备份参数。

### 10.1 光流模块基础参数

| 参数 | 数值 | 说明 |
|---|---|---|
| FLOW_TYPE | 8 | 光流传感器类型（upflow） |
| SERIAL2_PROTOCOL | 18 | Telem2 串口用于光流数据 |

### 10.2 EKF3 基础配置

| 参数 | 数值 | 说明 |
|---|---|---|
| AHRS_EKF_TYPE | 3 | 使用 EKF3 |
| EK2_ENABLE | 0 | 关闭 EKF2 |
| EK3_ENABLE | 1 | 启用 EKF3 |
| EK3_SRC_OPTIONS | 0 | 禁用所有速度融合 |

### 10.3 EKF3 默认（GPS 模式）

| 参数 | 默认值 | 说明 |
|---|---|---|
| EK3_SRC1_POSXY | 3 | 水平位置：GPS |
| EK3_SRC1_POSZ | 1 | 垂直位置：气压计 |
| EK3_SRC1_VELXY | 3 | 水平速度：GPS |
| EK3_SRC1_VELZ | 3 | 垂直速度：GPS |
| EK3_SRC1_YAW | 1 | 航向：指南针 |

### 10.4 激光雷达（Rangefinder）

| 参数 | 数值 | 说明 |
|---|---|---|
| SERIAL4_PROTOCOL | 9 | 串口用于激光雷达 |
| SERIAL4_BAUD | 115 | 波特率 |
| RNGFND1_TYPE | 20 | Benewake 串口雷达 |
| RNGFND1_MIN_CM | 10 | 最小测距 |
| RNGFND1_MAX_CM | 1000 | 最大测距 |
| RNGFND1_GNDCLEAR | 10 | 安装离地高度 |

### 10.5 光流 + GPS 切换（双源 EKF）

**主定位源（GPS）**：EK3_SRC1_POSXY=3 / POSZ=1 / VELXY=3 / VELZ=3 / YAW=1
**次定位源（光流）**：EK3_SRC2_POSXY=0 / POSZ=2 / VELXY=5 / VELZ=0 / YAW=1

| 参数 | 数值 | 说明 |
|---|---|---|
| RC6_OPTION | 90 | 切换 EKF 定位源 |
| EK3_FLOW_DELAY | 10 | 光流延迟 |

**常见坑**：切换光流报错 = `RNGFND1_MIN_CM` 太大；无法解锁 = `ARMING_CHECK` 未关 GPS；光流不生效 = `EK3_SRC1_VELXY ≠ 5`；飘/不稳 = `EK3_FLOW_DELAY` 未调。

### 10.6 光流测试流程

1. 重启后长按安全开关，飞控 LED 变蓝。
2. 切换悬停 (PosHold) 模式，室内会闪黄灯（无 GPS），可能出现 `PreArm: Need Position Estimate`。
3. SWG（乐迪）/SWC（Flysky）开关切到中位，用光流定位，稍等几秒 LED 转蓝，消息框出现 EKF3 融合光流提示。
4. 遥控器正常解锁，电机怠速即设置成功。
5. 若仍闪黄灯：检查 `RNGFND1_MIN_CM = 10`（默认 20，脚架高度不够会报错）。

**室外飞行测试**：① GPS 悬停（PosHold）；② 光流定位悬停（Loiter）；③ 前两次成功后可在飞行中切换定位源。**光流定位请在低空（5 米以下）使用。**

## 12. 外设与高级开发（图传 / MAVLink / 雷达 / 仿真）

### 12.1 WiFi 数传模块与图传

- 推荐 ESP8266 或思翼 WiFi 模块连接飞控串口，`SERIAL2_BAUD = 57600`，协议 MAVLink，即可用手机 QGC / Mission Planner 连接。
- LQ 图传模块支持 HDMI 及 AV 输入，配合树莓派构建 FPV 数字图传；模拟图传接摄像头和 5.8G 发射，频率需与接收机匹配。

### 12.2 舵机（投放器）

- 通过 Pixhawk AUX 通道控制舵机，`RC9_FUNCTION = 51`（Servo9），在 Mission Planner 中用脚本或遥控器开关触发投放。

### 12.3 树莓派 PWM 与舵机

- PWM 概念：周期 T、频率 f = 1/T、占空比 D = 高电平时间 / 周期。
- 呼吸灯：双色 LED 红灯接 GPIO12(PWM0)、绿灯接 GPIO13(PWM1)。
- SG90 舵机：5V 供电，周期 20ms 的 PWM，高电平 0.5–2.5ms 对应角度：

| 高电平持续时间 | 舵机角度 |
|---|---|
| 0.5ms | -90° |
| 1.0ms | -45° |
| 1.5ms | 0° |
| 2.0ms | 45° |
| 2.5ms | 90° |

- 占空比换算：`2.5 + angle * 10 / 180`。
- **安全提示**：测试前先拆桨叶；不要用树莓派 GPIO 直接给舵机供电（只输出控制信号，外部 5V 供电）。

### 12.4 MAVLink 自主控制（Python + pymavlink）

基础流程：`连接飞控 → GPS 就绪 → EKF 就绪 → GUIDED 模式 → 解锁 → 起飞 → 速度控制 → 停止 → LAND 降落`。

任务示例：前进 10 米降落 / 前进+后退 10 米 / 圆形飞行（前向速度 + yaw_rate）/ 8 字飞行 / 波浪高度飞行。

- 默认连接 UDP 端口 14550（SITL 或机载计算机转发）；实机改 `fcu_url` 为串口设备（如 `/dev/ttyACM0:921600`）。
- 安全提示：实机测试前确认遥控器接管、急停、LAND/RTL 模式和飞行区域安全。

### 12.5 YOLO 视觉识别

- 学习顺序：摄像头采集 → Full HD 图片采集 → 实时检测 → 无界面保存 → 自动录像 → 接入 MAVLink 任务。
- 检测脚本默认模型 `/home/drobotics/yolov8n.pt`；树莓派/Jetson 部署注意模型路径、摄像头编号、目录权限、散热。

### 12.6 MAVLink 数据转发

- 通过树莓派将 Pixhawk MAVLink 数据实时转发至 Windows 地面站，支持解锁/起飞/航点/速度控制/自动降落，可扩展多机编队、自动巡检、视觉导航、SLAM。
- 已在 Pixhawk + Raspberry Pi + LQ3 架构下完成实机验证。

### 12.7 A1 RPLidar 与 Pixhawk 集成

A1 RPLidar 规格：测量半径 0.15m–12m、360°、8000 次/秒、扫描频率 5–15Hz、供电 5V/1A（**必须独立 UBEC 供电，禁止从飞控取电**）、TTL 串口（3.3V/5V 兼容）。

参数配置：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| SERIAL4_PROTOCOL | 9 | 串口协议 = 激光雷达 (Lidar) |
| SERIAL4_BAUD | 115 | 波特率 115200 |
| RNGFND1_TYPE | 20 或 24 | 20 = Benewake Serial，24 = RPLidar A1 |
| RNGFND1_MIN_CM | 20 | 最小测量距离 20cm |
| RNGFND1_MAX_CM | 1200 | 最大测量距离 12m |
| AVOID_ENABLE | 2 | 启用避障功能 |
| AVOID_MARGIN | 150 | 避障距离 1.5m（cm） |

接线（A1 RPLidar ↔ Pixhawk）：

```
A1 RPLidar                Pixhawk 飞控
  VCC (红) → UBEC 5V+     TELEM2 / SERIAL4/5
  GND (黑) → UBEC GND       TX → 雷达 RX
  RX  (白) → 飞控 TX        RX → 雷达 TX
  TX  (绿) → 飞控 RX        GND → UBEC GND
                          UBEC 5V/2A（Input 3-6S 电池）
```

常见问题：雷达不转 = 供电不足/接线错；无测距数据 = SERIAL4_PROTOCOL≠9 或 RNGFND1_TYPE 错；数据跳动 = 供电干扰/震动；避障无效 = AVOID_ENABLE 未开。

### 12.8 SITL 仿真与红外精准降落

- SITL：实机测试前验证任务脚本、MAVLink 转发、飞行模式切换（解锁/起飞/航点/返航/降落）。
- 红外精准降落：基于 IR 锁定和视觉引导，I2C 红外传感器实现厘米级精度，设置 `PLND_ENABLED = 1` 及 `PLND_TYPE` 参数。

## 附：安全要点汇总

1. 桨叶安装错会无法起飞/侧翻，正反桨对照机臂标签，有字面朝上。
2. 电池 XT60 禁止反接；BB 响红线在最右，勿反插；锂电起火切勿用水。
3. 4S 电池充电上限 16.8V、单片放电下限 3.3V、存储电压 3.85V。
4. GPS 箭头前向必须与机头一致；LED 蓝 = 未定位、绿 = 定位成功。
5. 解锁手势（美国手）：油门最低 + 方向最右 2 秒；上锁：油门最低 + 方向最左 2 秒。
6. A1 RPLidar 必须独立 5V/1A UBEC 供电，禁止从飞控取电。
7. 光流定位仅限低空（5m 以下）；手动降落不可急拉油门。
8. 实机测试（MAVLink/舵机/电机）前先拆桨或绑飞验证。
