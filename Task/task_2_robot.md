# Task 2: Robot

> 状态：设计中
> 创建日期：2026-07-07

## 目标

实现 `Robot` — 长期运行的 tokio task，作为整个机器人系统的中枢。

## 定位

Robot 不是薄 Adapter，而是**自主智能体**：

```
决策层
  │   robot.go_to(10.0, 20.0)       ← 只需说目标
  ▼
┌─────────────────────────────────────────┐
│  Robot（长期 tokio task）                 │
│                                         │
│  select! {                              │
│    命令: go_to(x,y)                     │
│      → 路径规划 → while 还没到           │
│        → stm32.forward(50)              │
│        → if lidar.detect_obstacle()     │
│          → 绕障                         │
│                                         │
│    事件: 传感器状态更新                   │
│    事件: 低电量 → 自动回充               │
│  }                                      │
└─────────────────────────────────────────┘
  │  持有
  ▼
  STM32 / LiDAR / Camera ...
```

## 职责

1. 持有所有 Device，管理其生命周期（启动/关闭）
2. 内部 select! 聚合命令和传感器事件
3. 执行自主行为（导航、避障、回充等）
4. 对外提供统一 API（`go_to`, `stop`, `get_state` 等）
